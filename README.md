🎮 Rock Paper Scissors Game

An interactive Rock Paper Scissors web game built using HTML, CSS, and JavaScript.
This game follows a Best of 3 format where the player competes against the computer.

🚀 Features

🎯 Best of 3 match system

🤖 Computer auto random choice

📊 Live score tracking

✨ Smooth animations & clean UI

🔁 Reset game option

📱 Responsive design (Mobile friendly)

🛠️ Technologies Used

HTML5

CSS3

JavaScript (Vanilla JS)

🎲 How to Play

Select Rock, Paper, or Scissors

Computer randomly selects its move

Winner of each round is calculated

First to win 2 rounds wins the match

Click Reset to play again
